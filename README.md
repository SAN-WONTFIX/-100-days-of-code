# 100 Days of Code — SAN

Starting from scratch with DSA fundamentals (Arrays, Strings, Loops) and building up daily.
Goal: build consistency, prep for placements, target 15+ LPA roles.

## Rules
- Code at least 30–45 min every day
- Push a solution + a one-line takeaway daily
- No zero days — if short on time, do at least 1 easy problem

## Roadmap

- **Days 1–14:** Arrays & Strings (Easy)
- **Days 15–28:** Linked Lists, Stacks, Queues + basic Recursion
- **Days 29–45:** Sorting, Searching, Basic Math/Bit Manipulation
- **Days 46–60:** Trees & Basic Graphs + start flagship project
- **Days 61–80:** Dynamic Programming basics + project deep-work
- **Days 81–100:** Mixed practice, mock interviews, project polish, open-source PRs
